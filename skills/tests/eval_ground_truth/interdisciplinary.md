## Notes

- **Why this file exists (the routing test).** The four single-faculty GT files each test discovery *within* one faculty. This file tests the harder thing: an interest that genuinely spans faculties. The pass condition is **coverage across faculties** — a good run surfaces the Law leg (Finck), the ethics-center leg (Heesen / Ammicht Quinn), *and* the technical-ML leg (Hardt), rather than collapsing onto whichever single faculty its first query happened to hit. If a run returns only law chairs, or only ML chairs, that is an interdisciplinary-routing **miss** even if within-faculty recall looks fine.
- **Recall for this file** = of the 5 cross-faculty anchors above, how many the run surfaces — *and* whether it surfaces at least one from **each** of the three faculties/centers. Report both the count and the per-faculty coverage.
- **Interfaculty centers are first-class here.** The IZEW (International Center for Ethics in the Sciences and Humanities) and Cyber Valley / MPI-IS are **not under a single faculty's chair page**, so the faculty-backbone crawl alone will miss them. Discovery must also hit the interfaculty entry points (`uni-tuebingen.de/forschung/zentren-und-institute/…`, `is.mpg.de`, `cyber-valley.de`) — the same weak-web-presence / off-backbone gap noted in the backbone file's caveats. This is the intended stress on the backbone.
- **Adjacent / also-relevant (not in the core count, score as relevant if surfaced):** the Carl Friedrich von Weizsäcker-Zentrum project **"Ethics and Epistemology of Machine Learning"** (interfaculty, philosophy ↔ ML); Prof. Dr. Thomas Potthast (IZEW board speaker, ethics of science).
