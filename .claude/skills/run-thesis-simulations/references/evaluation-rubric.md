# Thesis Simulation Evaluation Rubric

Score each dimension from 0 to 3.

| Score | Meaning |
|---|---|
| 0 | Missing or seriously wrong |
| 1 | Present but shallow, generic, or partially incorrect |
| 2 | Mostly correct with minor gaps |
| 3 | Strong, specific, and evidence-aware |

## Dimensions

1. **Workflow compliance** - uses `thesis-finder`, builds the profile first,
   asks the track question, runs the selected discovery track(s), and reaches a
   natural endpoint.
2. **Profile depth** - captures interests, methods, domain, thesis style,
   skills, and no-gos with enough evidence from the simulated student.
3. **Department routing** - routes according to the student's actual field
   across all possible Tuebingen departments, not by defaulting to CS/ML.
4. **Evidence discipline** - uses current public sources when required and does
   not invent openings, capacity, citations, datasets, contacts, or URLs.
5. **Recommendation quality** - final chair/topic/company guidance follows from
   the profile and evidence, including honest no-fit outcomes.
6. **Persona realism** - simulated student answers match the command persona,
   disclosure rules, and response style without acting like an evaluator.
7. **Conversation usefulness** - the final output gives a student a practical
   next step, outreach angle, or clear explanation of what to verify.

## Verdict Bands

- **18-21:** strong pass
- **14-17:** pass with gaps
- **9-13:** weak run; needs skill or command improvements
- **0-8:** fail; rerun or redesign needed

## Required Notes

For every score below 2, include:

- what failed
- where it appeared in the conversation
- whether the failure came from the command, the simulated student behavior, the
  thesis skill, missing tools/web access, or the evaluator
- a concrete improvement suggestion
