# Meine Ideen

Zusammen mit dem Agent ein kleines Profil über sich ausarbeiten, das ehrlich ist und auf den Punkt trifft (Baseline), was dann auch gespeichert wird, wie die schon vorgeschlagenen stellen (sodass man es wiederverwenden kann). Und daraus dann einen vorschlag machen für ein spezifisches Anschreiben für eine high-signal first-contact-Mail.

Aber ausdrücklich vorher auf relevante Paper verweisen, sodass diese angeschaut werden (einen Überblick geschaffen wird). Sonst ist das ganze an der Sache vorbei. Ausdrücklich empfehlen Paper vorher versuchen zu verstehen, weil es auffällt in einem gespräch wenn man sich nicht anschaut, womit die researcher sich beschäftigen. Und dass das gute zusammenarbeit fördert.
