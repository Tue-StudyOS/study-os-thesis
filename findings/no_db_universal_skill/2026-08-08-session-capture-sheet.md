# Session capture sheet — one copy per tester (Task Z′)

Instrument for [the beta test protocol](2026-08-08-beta-test-protocol.md). Copy this file
per tester, fill it live during the session, keep it verbatim. Do **not** tidy up wording
afterwards — the verbatim statements are the primary result.

**Rules that are easy to break under time pressure, listed here so they aren't:**

- §1a is taken **before** the tester opens INSTALL.md or the tool. Once they've read
  anything, the baseline is gone.
- §2: **do not help.** Where they get stuck is the measurement. Record it and stay quiet.
- §3: the post-statement **is** the tool's own N6 answer. Do **not** re-ask it externally.
- §4: (a) and (b) are scored **with** the tester. On disagreement, record both judgements.
- §5: never quote the 48 s figure to the tester, before or during.
